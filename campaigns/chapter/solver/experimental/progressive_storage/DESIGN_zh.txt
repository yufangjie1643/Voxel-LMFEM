渐进损伤兼容的混合材料存储设计
2026-10-21；状态：接口设计＋CPU 参考原型，尚未接入 CUDA 主算子。

一、当前代码的约束与改动动机

旧版 repro/source/femlib/hybrid_material.py 将固定全局材料共享为 C21 表，
局部取向体素保存预旋转 C21，int32 索引指向统一系数池。
experiments/hybrid_operator_20261021/operator_adapter.py 在 split_delta 下将
该池原地改为 C-Cb，活动集合仅由 phase != background_phase 确定，参考材料
也被缓存。这是静态弹性接口，不能直接在共享行上更新一个体素的损伤。

另一个已有渐进损伤分支 fe2_open_hole_20261020/progressive/engine.py::install
使用两相×完整/退化两状态，但仍将状态展开成整场 C21 并重建 HG 算子。
这说明现有材料数据足以验证“状态查表”，但那条 HG 路线不是新的 FI 路线。
本设计保留两份旧代码及已有论文结果，新增独立原型，不改变默认求解器。

二、数据模型：共享参数，独立历史

MaterialCatalog（不随损伤步修改）
  材料标签、初始弹性参数、材料坐标系、损伤模型标识、强度/演化参数。
  可选完整/退化有限状态 C21 表；可选局部取向的初始 C21 池。
  几何身份只使用 phase_id 和可选 orientation，不依赖 yarn_id。

HistoryField（每个材料点独立）
  location = element | gauss8，必须显式声明。
  committed / trial；状态包含损伤变量及该本构所需的最大历史量、耗散等。
  相同 phase_id 可以拥有不同历史；材料身份不等于损伤状态。
  FE² 中每个宏观积分点拥有独立历史，静态相表/方向表可以跨 RVE 共享。

MaterialAction（计算接口）
  stress(strain, history)、apply_frozen(v)、update_trial(strain, history_n)、
  可选 apply_algorithmic_tangent(v)、energy、commit、rollback。
  update_trial 必须返回脏材料点、历史版本，以及对称/正定等求解器能力标记。
  实际力学定律决定历史与切线；存储层不自行设定断裂能、残余刚度或损伤准则。

CPU 原型 SharedStateMaterial 实现的子集：
  有限且有序的不可逆离散状态、C(d)=(1-d)C0 标量状态、element/gauss8，
  begin_trial/update/commit/rollback/frozen、版本号和背景损伤活动集合。
  catalog 接收预先定义的全局坐标张量；局部方向构造和通用本构插件尚待接入。
  points=1 表示每单元一个历史变量，力学积分依然为八点 FI，绝非单点积分。

三、按本构结构选择精确表示

1. 有限状态：C_e,q = C_table[phase_e, state_e,q]。
   已有两相×完整/退化只有 4 个 C21，共 672 字节；损伤后只改状态索引。
   不能让一个局部点的损伤覆盖共享材料行。
   对任意空间变取向，仍须旋转应变/应力或保留旋转后的局部行；不能声称
   只有这 4 行就覆盖了任意不同全局取向且无需旋转开销。

2. 标量连续损伤：C_e,q(d)=g(d_e,q) C0_e。
   应力为 g(d) [C0_e epsilon]，只保存标量状态；不构造每点新 C21。
   若状态在单元内一致，由线性性 K_e(d)u=g(d_e) K_e(C0)u，
   原 FI 模态计算可复用，并把 g 融入输出乘法。
   原型只验证 g=1-d；实际演化函数必须来自用户选用的本构。

3. 多模式/局部各向异性：优先调用本构的精确乘法。
   若本构确有 C(d)=sum_a c_a(d) C_a 的低维精确展开，可共享 C_a；
   否则在局部坐标作用：epsilon_l=T_e epsilon_g，sigma_g=T_e^T sigma_l。
   T_e 是工程应变的能量共轭变换，不能把工程剪应变当普通六维旋转向量。
   几个损伤变量并不自动保证任意张量都存在同样维数的固定基展开。
   重复求解很多次且重构昂贵时，可仅为脏/受损点缓存 C21，并记录缓存版本；
   缓存只是速度/存储选项，必须与本构精确作用一致。

四、与均匀背景＋差值算子的衔接

对冻结历史 z：
  K(z)=Kb + sum_e R_e^T [sum_q w_q B_q^T (C_e,q(z)-Cb) B_q] R_e。

活动集合应为非背景初始材料 A0 与损伤影响集合 D 的并集；
更精确地可用存在 q 使 C_e,q(z)!=Cb 的元素集合。
不能继续只用初始 phase_id 判断；背景基体损伤会新增活动元素。
离散状态后期可按“当前相-状态”的占比重新选择共享背景，再重建小模板。
重新选背景只允许发生在线性求解之间，且从物理材料/状态重新构造差值。

若旧存储已经是 DeltaC0=C0-Cb，标量损伤必须使用
  DeltaC(d)=g(d) DeltaC0 + (g(d)-1) Cb。
仅令 DeltaC(d)=g(d)DeltaC0 会漏掉背景退化，尤其在 DeltaC0=0 处完全错误。
新设计保留不可变材料身份/物理参数，让差值成为可重建缓存，禁止重复原地扣背景。

周期 RHS 仍可仅由差值计算；平均应力仍可补回 Cb E，前提是八点加权一致，
周期波动平均应变为零。独立残差认证必须从当前物理材料与当前历史计算。

五、八积分点损伤与模态优化

当前精简 FI 模态核使用单元内恒定 C 的积分化简。若 C_e,q 随 q 改变：
  K_e=sum_q w_q B_q^T C_e,q B_q，
通常不等于使用八点平均 C 的常系数 K_e。模态之间原来消失的耦合可重新出现。

保持原离散问题的建议路径：
  未损伤单元：原 FI 模态快速路径；
  单元内同一损伤状态：常系数 FI 模态或标量乘法路径；
  积分点状态不同：完整八点本构作用，仅添加精确损伤修正。
对应恒等式为 K_e(z)=K_e(C0_e)+sum_q w_q B_q^T[C_e,q(z)-C0_e]B_q。
活动比例很高时，应比较直接全域损伤核与背景修正核，避免重复计算与抵消。
本次未实现 GPU 核路由，不能承诺仍保持静态弹性时的全部速度收益。

六、求解与缓存生命周期

载荷增量开始 -> 从 committed 建立 trial -> 冻结 trial 并求平衡 ->
恢复各材料点应力/应变 -> 本构更新 trial -> 有变化则重启平衡 ->
无新变化且平衡通过则提交；不收敛则回滚并交还增量控制器处理。

一次标准 PCG 内 K 与预条件器固定；损伤变化后重新计算残差并重启 PCG，
可以使用上次位移作为初值，但不能直接继承原共轭方向。
FFT 的几何计划、频率排列和缓冲区可复用；参考系数可在两次求解之间刷新。
固定的旧 SPD 参考预条件器在满足假设时仍可用，但损伤后迭代数可能上升。
等效刚度、混合宏观边界约束、对角项等依赖刚度的缓存必须按版本失效。

冻结损伤下若剩余刚度正定、约束去掉刚体零模，可继续 PCG。
完整一致算法切线还包含损伤演化导数，软化时可能不正定或不对称，不能仅凭
初始材料 SPD 就沿用 PCG。接口须区分 frozen_secant 与 algorithmic_tangent。
节点与积分点均保留。若本构允许零刚度/失连，需另行处理零空间与求解器，
不能为让 PCG 运行而未经定义地添加残余刚度。

七、存储核算（仅逻辑数组，不是 NVML 或实测峰值）

N=192^3，Q=每单元状态点数，m=每点 FP64 历史标量总数：
  C21 全场：168N 字节；每积分点 C21 则为 168QN。
  稠密历史：8mQN；uint8 离散状态为 QN。
  committed 与 trial 双缓冲需再加一份历史；求解向量、FFT、局部方向、
  活动索引、临时工作区、分配器缓存都要另外计算。
  若可由历史量唯一导出 d，可以不另存 d，但必须说明重算成本。

稀疏历史只适用于缺省状态确实足够的材料点，不能丢掉损伤起始前必需的历史。
若 S=QN，有 int32 的全域 slot_map、int32 活动点 id 和 m 个 FP64 状态，
单份稀疏历史约 4S+(4+8m)A，稠密为 8mS；只比较这些数组，稀疏更小需
A/S < (8m-4)/(8m+4)。双缓冲、容量空闲、对齐和映射复用会改变分界。
当前 CPU 原型先使用稠密历史；稀疏/稠密自动切换属于后续 GPU 实现。
