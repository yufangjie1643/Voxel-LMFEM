# HEX8 精确模态 GPU 对照

该目录将 CPU 验证过的 HG 和 FI 模态算子移植到原生 CUDA。实验目标是在同一个 192³ 周期编织 RVE、RTX 5090 和论文冻结运行环境中，对比论文配置与新算子。

HG 的论文基线为 C21、原 CUDA thread128 两阶段直接计算和混合精度 FFT 预条件。FI 的论文基线为 14 点缓存、原 CUDA thread128 和相同的混合精度 FFT 预条件。新方案保留原载荷、参考预条件器、PCG 向量更新、真实残差认证和应力恢复，只替换刚度作用。

## 文件

`generate_cuda.py` 从相邻 CPU 实验目录的 `generated_kernels.py` 提取标量模态函数，生成 `modal_kernels.cu`。CUDA 中不形成单元刚度矩阵，计算保持 FP64，并关闭 fast math。该文件实现三种组装：N×24 缓冲的两阶段、直接原子累加、双层共享内存的逐层分块。逐层分块只保存两个 z 层的单元力，共享内存用量不随块的 z 长度增长。

`modal_adapter.py` 编译扩展并接入冻结算子的 `apply` 接口。`gpu_study.py` 负责小网格独立验证、192³ 单算子调参、正式三次完整测量及 GPU 占用监控。`run_controls.py` 另测原代码已有的 HG 原子分支与 FI 八点积分原子分支，用于分离模态计算与组装组织的收益。

## 冻结环境

论文原运行目录为 `/home/yufan/code/runtime`，可用 `FEAD_RUNTIME` 指定同结构的冻结副本。默认解释器为 `/home/yufan/uv-torch-py312/bin/python`。正式实验要求 RTX 5090、PyTorch 2.12.0+cu130、CUDA 13.0，物理计算采用 FP64，参考采用 FP32/complex64、实数半谱及六项 Hermitian 表示。

代码复制到单独目录执行，冻结源文件保持原样。每份结果保存 GPU UUID、输入哈希、源文件哈希、数值协议和逐阶段峰值。

## 执行

在实验目录内，先完成 CPU 生成和 GPU 编译，再执行串行流水线：

```bash
/home/yufan/uv-torch-py312/bin/python -u gpu_study.py --phase orchestrate --grid 192
```

流水线先用 5×6×7、边长不等的任意正定各向异性材料，与独立 CPU CSR 直接解比较。验证阈值为 10⁻¹⁰，检查节点算子、位移、局部应力和完整等效刚度。通过后在 192³ 测量预先列明的两阶段、原子和逐层分块配置，以 CUDA 事件计量单次刚度作用，再选定单算子最快配置。

正式比较包含原论文配置、固定 thread128 的模态两阶段配置，以及调参选定的新配置。每种配置使用三个独立进程，各完成一次同尺寸、六载荷完整预热，再进行一次正式均匀化。三次配置顺序交错。正式真实相对二范数残差阈值为 10⁻⁸，最多 10000 次迭代。

完整计时包括 GPU 材料构建、算子和参考初始化、全部右端项、求解、真实残差及应力恢复；排除 CPU 几何、磁盘、首次编译与预热。额外的候选接入阶段同步对所有配置一致。单算子计时单独报告。

原生原子分支的补充对照：

```bash
/home/yufan/uv-torch-py312/bin/python -u run_controls.py --phase orchestrate --grid 192
```

该脚本等待主流水线正常完成后使用 GPU。所有任务串行运行；检测到其他 GPU 进程时，只停止本实验任务并保存状态。
