# Contributing

Describe the mechanics problem, expected behavior and a small reproducible input in an issue or pull request. Include Python/PyTorch/CUDA versions where relevant.

Install the dev extra and run docs/validation.md checks. Keep edits focused and use physical/analytical regression tests. Preserve Voigt conventions, boundary conditions and true-residual checks.

Keep output in runs/ and preserve frozen campaigns. Document measurement-protocol changes; CPU reference tests do not establish GPU performance gains.

Existing attribution and terms are described in NOTICE.md. No additional license grant has been assigned to author-owned code.
