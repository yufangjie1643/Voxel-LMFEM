# Research data

- `paper/`: numerical comparisons, convergence and performance records.
- `woven/`: yarn-fraction results and experiment snapshots.
- `chapter/`: chapter input files and solver snapshots.
- `sources/`: numerical implementation snapshots.

Use `uv run --no-sync voxel-lmfem reproduce` from the repository root to generate the paper tables. See the [reproduction guide](../README.md) for benchmark commands and data conventions.
